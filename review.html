How to draw and correct

Right-click the canvas to choose Select, Draw box, Draw line, or Draw boundary. Line/boundary points snap to visible connection anchors; connected annotations move together. Use the Finish drawing button above the canvas when the line or boundary is complete.

Homerun tags are symbols; visible circuit paths belong to Observed wiring. Never guess hidden routes. Mark reviewed does not approve training.

Multi-select: Shift+Click items in the Annotations list below, or shapes on the drawing, to select several at once. Apply changes / Mark reviewed / Reject then act on the whole selection. Use Group (or Ctrl+G) to make a multi-selection move together as one from now on, and Ungroup (or Ctrl+Shift+G) to split them apart again. Boxes no longer link to nearby boxes automatically — grouping is always your choice.

Keyboard: Ctrl+Z undo (zoom stays) · Ctrl+Y or Ctrl+Shift+Z redo · Ctrl+C copy · Ctrl+V paste · Backspace reject / remove last point · Esc cancel drawing · F fit page · + / − zoom · T dark / light.

Mouse: Right-click opens the tool menu. Right-button dragging never edits or duplicates an annotation.

    Quick guide

    Navigate a drawing

    • Fit page resets the view. Rotate spins the page 90° for readability.
    • + / − zoom; drag with Select / pan to move around.
    • Pick a Group, then a Drawing, at the top.

    Correct an annotation

    • Click a shape or a row in the Annotations list to select it.
    • Change its type, class (searchable), or label, then Apply changes.
    • For walls, set the Wall / opening type (e.g. glass) once "Wall / room / opening" is chosen.

    Draw something new

    • Draw box: drag a rectangle. Draw line / boundary: click each point, then Finish drawing.
    • Move / reshape: drag the outline or corner handles of a selected mark, or right-click it → Move / reshape. Backspace removes the last point of a line / boundary.

    Work faster

    • Right-click the drawing for the tool menu — select, draw, move / reshape, review, or reject.
    • Ctrl+C copies and Ctrl+V pastes the selected annotations; Backspace rejects.
    • Ctrl+Z / Ctrl+Y undo and redo — your zoom stays put.
    • Shift+Click multiple items to bulk-edit them together.
    • T switches dark / light mode. Search the annotation list or the legend class list to jump straight to what you need.
    Coverage across all drawings

    Partial proposals, not installed-device quantities. Unmarked areas are not negative training labels.
